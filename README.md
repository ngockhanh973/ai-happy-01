# ai-happy-01

An entry for make.fun's "Make the AI judge happy" competition.

The image: a golden retriever puppy leaping through a swirl of autumn
leaves in warm golden-hour light, a tiny sparrow riding on its back —
one small, specific moment of pure joy.

`main.py` copies `entry.png` byte-for-byte to `/output/entry.png`, so
every run produces exactly the same file.
